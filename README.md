# Afsar Ali Golf Academy

A premium static website for former professional player and golf coach **Afsar Ali**. It is built with HTML, CSS and vanilla JavaScript, so it runs directly on GitHub Pages without a server or build step.

## Pages

- Home (`index.html`)
- About Afsar (`about.html`)
- Programs (`programs.html`)
- Pricing (`pricing.html`)
- Gallery with Lightbox (`gallery.html`)
- Testimonials with Swiper (`testimonials.html`)
- FAQ (`faq.html`)
- Contact and booking request (`contact.html`)

## Local preview

Open `index.html` in a browser. No package installation is required.

## GitHub Pages deployment

1. Push this repository to GitHub.
2. In the repository, go to **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select the branch containing this website and the `/ (root)` folder.
5. Save. GitHub will publish the site at the URL shown in Pages settings.
6. Update `sitemap.xml` with that final published URL.

## Before launch

- Replace the placeholder WhatsApp number (`+92 300 000 0000`) and email address with Afsar’s real contact details.
- Add the final social media profile links in each footer.
- Replace any Unsplash images with owned academy photography if desired. The supplied Afsar coaching video is published at `assets/images/afsar-ali-coaching.mp4`.
- The contact form uses browser storage to provide a static-site confirmation. For emailed lead notifications, connect it to a form service such as Formspree, Netlify Forms, or a Google Apps Script endpoint.
